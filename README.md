# Keycloak Mappers


*   **`AttributeFallback.java`**: Use any user attribute as OIDC claim, with option to fallback on another attribute
*   **`CustomFallback.java`**: Use any user attribute as OIDC claim, with option to fallback on hardcoded value
*   **`UPNMapper.java`**: Maps the user's username with '@' and a specified domain name to email claim if email not available
